1. How to Launch the System

Make sure both the backend and frontend are running before performing the tests:

  • Option A (1-Click Windows): Double click start_all.bat in the project root folder.
  • Option B (Python Launcher): Open PowerShell and run python start_app.py.
  • Option C (Manual):
    • Terminal 1: python backend/run.py (Running at http://127.0.0.1:8000)
    • Terminal 2: cd frontend && npm run dev (Open browser at http://localhost:5173)

2. Explanation of the 7 Form Input Fields

Input Field Allowed / Expected Values How the System Preprocesses It (Notebook 02 Feature Engineering)
Violation Description
description		 Free-text description from DOB summons (e.g. "FAILURE TO MAINTAIN...") NLP Leakage Masking strips direct labels (CLASS 1/2/3, IMMEDIATELY HAZARDOUS), replaces URLs with URL, dates with DATE, and permit numbers with IDNUM. Tokenized into TF-IDF 1-2 n-grams (40,000 max features).
Borough
borough		 1 (Manhattan), 2 (Bronx), 3 (Brooklyn), 4 (Queens), 5 (Staten Island) Cast to string. One-hot encoded.
Violation Type
violation_type		 12 NYC Categories (Construction, Boilers, Elevators, Cranes, Plumbing, Signs, Quality of Life, etc.) One-hot encoded (rare levels merged into infrequent category).
Respondent Name
respondent		 Entity or owner cited (e.g. "NYC HOUSING AUTHORITY", "ABC CORP LLC", "JOHN SMITH") Rule-based PII categorization into GOVERNMENT, ORGANISATION, or INDIVIDUAL.
Issue Date
issue_date		 Calendar date (YYYY-MM-DD) Decomposed into ISSUE_MONTH, ISSUE_DAYOFWEEK (0 to 6), and IS_WEEKEND (1 if Saturday/Sunday).
Aggravation Level
aggravation_level		 No Aggravation (0), Aggravated Level 1 (1), Aggravated Level 2 (2) Ordinal mapping to 0.0, 1.0, or 2.0.
Building ID (BIN)
bin		 7-digit NYC Building Identification Number (e.g. 1000007, 2026562) Looked up against bin_history_lookup.csv to compute: 1) BIN_PRIOR_VIOLATIONS, 2) BIN_PRIOR_CLASS1, and 3) BIN_DAYS_SINCE_PREV (capped at 1,000 days).

  2. Live Respondent Categorization: Type NYC HOUSING AUTHORITY in the Respondent input — notice the real-time badge updates immediately to Derived: GOVERNMENT. Type ABC CORP LLC — updates to Derived: ORGANISATION.
  3. Building History Live Lookup: Enter 1000007 in the Building ID (BIN) box and click "Check History". The backend queries bin_history_lookup.csv and instantly renders: Total Priors: 10 | Class 1 Priors: 7 | Last: 2026-09-02.
  4. Light & Dark Theme Switcher: Click the Theme Toggle button in the top-right header or bottom of the sidebar to toggle between sleek Dark Mode and high-contrast Light Mode.
  5. Feature Engineering Inspection: After submitting a prediction, expand the "Inspect Engineered Model Inputs (14 Features)" drawer. It shows the exact feature vector passed into the pipeline (demonstrates complete data flow integrity for the marking rubric).
  6. Batch CSV Triage: Click "Batch Triage" in the top header. Click "Load Demo 5-Case Batch" to process multiple records simultaneously, filter by "⚠️ Human Review", and click "Export Triage Report (CSV)".
  7. Model Audit Tab: Click "Model Audit" in the top header to inspect the 5 candidate models benchmark table from Stage 7, proving why Logistic Regression [tuned] was selected.

5. Viva Defense Notes (Why the Model Behaves This Way)

Examiner Question Prepared Technical Answer
Why Logistic Regression over LightGBM / XGBoost? In Stage 7, 4 of 5 models passed the recall floors (Class-1 $\ge 0.80$, Class-3 $\ge 0.55$). Logistic Regression achieved tied Macro-F1 ($0.7719$ vs $0.7748$ for LightGBM), but Logistic Regression had better Class-3 recall ($73.0\%$ vs $65.0\%$), produced smooth well-calibrated probabilities, and evaluated in $0$ ms.
Why was Linear SVM disqualified? Linear SVM achieved high Macro-F1 ($0.7768$), but Linear SVM only outputs signed decision margins, not calibrated class probabilities. Without probabilities, a safety threshold (confidence < 65% $\rightarrow$ inspector) cannot be computed.
How did you prevent data leakage? 1) Masked direct target vocabulary (CLASS 1/2/3) from text before TF-IDF.
2) Refitted TF-IDF vocabulary and Chi² feature selector inside each CV fold.
3) Building history counts strictly violations issued on earlier dates.
